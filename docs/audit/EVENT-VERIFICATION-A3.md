# Appendix A.3 Event Investigation — Sub-Events Not in Table 3-I

**Phase**: 0 (remediation)
**Source**: `docs/audit/EVENT-VERIFICATION-A3.md`
**Date**: 2026-07-13 (remediation)
**Spec reference**: APOLLO_11_PRODUCTION_SPEC §A.3 — _"Phase 0 必须从 Mission Report、launch vehicle flight evaluation、Technical Transcript、ALSJ/AFJ 和 recovery 资料中建立这些 Event ID。没有可靠 MET 时，可以保留在 Archive 叙事中，但不能驱动标为 `ACTUAL` 的精确动画。"_

## Purpose

The original Phase 0 release deferred all Appendix A.3 sub-event investigation to Phase 2 ("DEFERRED to Phase 2" for every row). This violated spec §A.3, which requires Phase 0 to **establish the Event IDs** with source candidates and verification status — not to defer the entire investigation. This document remediates that gap.

Per spec §A.3, each Event ID below has at minimum:

- A stable Event ID (matching the `a11-...` convention from Appendix A.1).
- A semantic label.
- A source-candidate list (which NASA source is most likely to contain the actual MET or qualitative description).
- A Phase 0 verification status.
- A processing rule when no reliable MET is available (per spec §A.3: _"没有可靠 MET 时，可以保留在 Archive 叙事中，但不能驱动标为 `ACTUAL` 的精确动画"_).

## Verification status vocabulary

- **MET-CONFIRMED** — a specific MET is present in an archived source and verified against extracted text.
- **MET-LOCATED-NOT-VERIFIED** — a MET is referenced in an archived source's extracted text but the OCR/text quality or surrounding context requires Phase 2 cross-check before publication.
- **QUALITATIVE-ONLY** — the source describes the event qualitatively (e.g. "staging occurred smoothly") without a specific MET; no `ACTUAL` animation may be driven from this.
- **SOURCE-IDENTIFIED-PENDING-MET** — the source that should contain the MET is identified and archived, but the specific MET has not yet been extracted (Phase 2 action with a bounded scope).
- **NOT-AVAILABLE-IN-SOURCE** — no archived source contains the event detail; the event may appear in Archive narrative but must NOT be driven as `ACTUAL` animation.
