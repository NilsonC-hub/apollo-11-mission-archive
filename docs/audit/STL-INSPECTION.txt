## CSM reconstruction relevance

Files of interest for ADR-006 CSM reconstruction:
- `service module.stl` — explicitly named, SM candidate
- `escape tower.stl` — LES, top of CSM stack
- `lem shroud.stl` — SLA (Spacecraft/LM Adapter), the conical adapter between S-IVB and CSM
- `command moduel.stl` — CM candidate. NOTE: the exact spelling "command module.stl" does NOT
  exist in this kit. The file is named "command moduel.stl" (note the original typo "moduel").
  This is the CM candidate — it is present, not absent.

Implication: Path 2 (STL kit) provides CM + SM + LES + SLA as a set.
However, without visual geometry verification (opening the STL in a viewer and confirming
the shape matches a conical Command Module), Path 2 is PROVISIONALLY viable, not confirmed viable.
The triangle count (3,652) and bounds (33.95 x 20.09 x 33.90) are consistent with a CM shape,
but visual confirmation is a Phase 3 action.
Recommendation: combine Path 2 (SM/LES/SLA + provisional CM) + Path 3 (CM from GLB) hybrid approach.
